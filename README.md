# 차별금지법 안내 사이트

디자인 가이드 v1.3(2026.10.21)을 적용한 정적 사이트입니다. Node.js와 Python 3.12 이상을 사용합니다. Python 생성기에는 외부 패키지가 필요하지 않습니다.

```sh
npm ci
npm run dev
```

개발 서버는 3000번 포트에서 실행하며 확장자가 없는 페이지 주소와 `.html` 리디렉션을 지원합니다. Vercel에서는 `vercel.json`의 `public` 출력 경로와 `cleanUrls` 설정을 사용합니다.

## 수정과 검증

- 원고와 공통 HTML: `scripts/build.py`
- 디자인 토큰·공통 컴포넌트·반응형 레이아웃: `public/assets/css/style.css`
- 메뉴·문답·장면 선택·연표 필터·공유: `public/assets/js/main.js`

```sh
npm run generate
npm run check
```

원고나 템플릿을 수정한 뒤 HTML을 생성하고, 변경된 `public/*.html`도 함께 반영합니다. 생성된 HTML만 직접 수정하면 다음 생성 시 사라집니다. `check`는 임시 디렉터리에서 다시 생성한 결과와 배포 파일을 비교하고 내부 페이지·앵커·자산 링크, 중복 ID, 접근성 속성의 참조를 검사합니다. 외부 사이트의 내용이나 법률 해석을 검증하는 명령은 아닙니다.

화면 변경 시 320·390·768·1100·1440px에서 글자 줄바꿈과 가로 넘침을 확인합니다. 키보드 메뉴 조작과 Escape 후 초점 복귀, 문답 검색·모두 펼침·직접 링크, 네 장면 선택, 연표 필터·시기 이동, 움직임 줄이기도 확인합니다. JavaScript가 꺼져도 페이지 탐색, 문답 펼침과 전체 장면·연표 읽기가 가능합니다.

## 디자인 기준

핑크 `#F375B5`, 퍼플 `#7056BE`, 옐로 `#FCD783`와 화이트·웜 그레이·잉크를 사용합니다. 본문은 18px/1.75, 제목은 Hahmlet 600·700입니다. 콘텐츠 최대 폭은 1,200px, 긴 본문은 720px입니다. 첫 화면의 검정 히어로는 가이드의 화면 예시를 따릅니다. 이전의 화면 전체 패널·굵은 테두리 스타일을 덧씌우지 않고 공통 컴포넌트로 관리합니다.

글꼴은 제공된 가이드에 포함된 Hahmlet와 Noto Sans KR의 WOFF2를 `public/assets/fonts/`에서 직접 제공합니다. 두 글꼴의 SIL Open Font License도 같은 디렉터리에 포함합니다. 외부 글꼴 서비스 연결은 필요하지 않습니다.

## 원고와 외부 연동

기존의 문답 9개, 일상 사례 23개, 연표 사건 11개, 자료 8개를 유지합니다. 홈에도 문답 9개를 표시하며 핵심 답변은 항상 보여주고 상세 설명은 펼쳐 읽습니다. 뉴스레터·리플렛·후원은 기존 외부 서비스로 연결하며, 실제로 연동되지 않은 이메일 수집 폼은 사용하지 않습니다.

공개 전에는 법률 설명과 입법 현황, ‘유엔 권고 14차례’의 목록·집계 기준·기준일을 검토해야 합니다. 조사별 수치와 질문·시점을 구분하고, 88.5%는 다른 질문에 대한 보조 근거로 표시합니다. 한국리서치 PDF는 제공된 원고의 주소로 연결했습니다. 원고의 조사 시점(2026 하반기), 디자인 가이드의 시점(2026년 5월), PDF 파일명의 시점(2025년 8월)이 달라 현재 날짜를 단정하지 않습니다. PDF 열람이 네트워크 정책으로 차단되어 시점과 링크 유효성은 추가 확인이 필요합니다. 자료 8개의 실제 URL과 연표 사건별 근거 링크도 아직 확인이 필요합니다. 주소가 없는 자료에는 동작하지 않는 링크 대신 준비 상태를 표시합니다.
