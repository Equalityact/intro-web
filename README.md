# 차별금지법 안내 사이트

디자인 가이드 v1.3(2026.10.21)을 적용한 정적 사이트입니다. Node.js와 Python 3.12 이상을 사용합니다. Python 생성기에는 외부 패키지가 필요하지 않습니다.

```sh
npm ci
npm run dev
```

개발 서버는 3000번 포트에서 실행하며 확장자가 없는 페이지 주소와 `.html` 리디렉션을 지원합니다. Vercel에서는 `vercel.json`의 `public` 출력 경로와 `cleanUrls` 설정을 사용합니다.

## 수정과 검증

- 제공된 원고: `content/manuscript.json`
- 상세 원고 원본: `content/details.txt`
- 제공된 타임라인 링크 원문: `content/timeline-links.md`
- 공통 HTML과 생성기: `scripts/build.py`
- 디자인 토큰·공통 컴포넌트·반응형 레이아웃: `public/assets/css/style.css`
- 메뉴·문답·공유: `public/assets/js/main.js`

```sh
npm run generate
npm run check
```

원고나 템플릿을 수정한 뒤 HTML을 생성하고, 변경된 `public/*.html`도 함께 반영합니다. 생성된 HTML만 직접 수정하면 다음 생성 시 사라집니다. `check`는 임시 디렉터리에서 다시 생성한 결과와 배포 파일을 비교하고 내부 페이지·앵커·자산 링크, 중복 ID, 접근성 속성의 참조를 검사합니다. 외부 사이트의 내용이나 법률 해석을 검증하는 명령은 아닙니다.

화면 변경 시 320·390·768·1100·1440px에서 글자 줄바꿈과 가로 넘침을 확인합니다. PC 상단 메뉴는 16px이며 항목 간격은 12px입니다. 키보드 메뉴 조작과 Escape 후 초점 복귀, 메인 오른쪽 하단의 섹션 이동·현재 위치 표시, 문답 검색·모두 펼침·직접 링크, 연표의 시기 이동, 움직임 줄이기도 확인합니다. 일상의 변화는 영역별 탭 4개에 원고의 23개 사례를 비교 카드로 제공합니다. 탭은 방향키·Home·End와 직접 링크를 지원합니다. JavaScript가 꺼져도 페이지 탐색, 섹션 링크, 문답 펼침과 전체 사례·연표 읽기가 가능합니다.

## 디자인 기준

핑크 `#F375B5`, 퍼플 `#7056BE`, 옐로 `#FCD783`와 화이트·웜 그레이·잉크를 사용합니다. 사용자가 과한 색상 사용을 줄여 달라고 요청하여, 색상 보강 전(`6a07136`)의 중립적인 배경과 기존 퍼플·핑크·옐로 포인트로 되돌렸습니다. 추가 변화는 약 20% 수준의 절제된 보완을 목표로 하며, 구역 제목의 짧은 핑크 밑줄과 자료 카드의 작은 핑크·옐로 표시(각 40×4px)에 한정합니다. 상세 페이지 도입부·카드·통계 상자를 진한 핑크나 옐로로 채우지 않습니다. 긴 본문은 흰 바탕을 유지하며, 주요 행동과 선택 탭에는 퍼플과 흰 글자를 사용합니다. 본문은 18px/1.75, 제목은 Hahmlet 600·700입니다. 상단 워드마크는 함렛체로 ‘차별금지법의 모든 것’ 한 줄만 표시합니다. 콘텐츠 최대 폭은 1,200px, 긴 본문은 720px입니다. 메인과 상세 페이지의 여론조사·권고 카드는 공통 생성 함수와 스타일을 사용합니다. 첫 화면의 검정 히어로는 가이드의 화면 예시를 따릅니다.

글꼴은 제공된 가이드에 포함된 Hahmlet와 Noto Sans KR의 WOFF2를 `public/assets/fonts/`에서 직접 제공합니다. 두 글꼴의 SIL Open Font License도 같은 디렉터리에 포함합니다. 외부 글꼴 서비스 연결은 필요하지 않습니다.

## 원고와 외부 연동

사용자가 제공한 원고를 `content/manuscript.json`에 보관하고 HTML은 이 원고에서 생성합니다. 상세 내용은 첨부 원본인 `content/details.txt`와 대조합니다. 원고의 문구를 고치거나 추가하려면 변경안과 이유를 먼저 보고하고 사용자 확인을 받아야 합니다. 디자인 가이드의 설명 문구를 사이트 원고로 사용하지 않습니다.

사용자가 명시적으로 복원·보완을 승인한 예외도 같은 JSON에 보관합니다. 6개 상세 페이지 상단의 `page_introductions`는 `2cb6e3f`의 소개 문장을 그대로 복원했습니다. ‘필요한 이유’의 시민·종교계·국제사회 구성과 강조 상자·문답 바로가기도 복원했습니다. 일상의 변화는 사용자 허용 범위에 따라 변화 전 상황·사유·영역 설명을 보완했고, 변화 후 문장은 원고의 23개 사례를 그대로 사용합니다. 이 예외들을 원고 외 문구라는 이유로 다시 삭제하지 않습니다. 사용자가 제외한 조사 방법·합산 수치 관련 안내, 조사 시점 보완 예정 안내, 공개 전 권고문 집계 확인 메모는 사이트에 표시하지 않습니다.

`npm run check`는 원고의 제목·본문이 상세 원본과 일치하는지, `data-manuscript`로 표시된 출력 문구와 나머지 한국어 본문이 원고에 있는지 검사합니다. 메뉴·검색·공유 상태 같은 기능 표시는 별도로 구분합니다. 미리보기·메타 설명도 원고의 문구를 사용합니다.

문답 9개, 일상 사례 23개, 연표 사건 11개, 자료 소개 8개를 유지합니다. 메인에는 앞의 질문 4개만 표시하며 기본 상태에는 질문만 노출하고 펼치면 자세한 답변을 보여줍니다. 더 알아보기는 9개 질문이 있는 Q&A 페이지로 연결합니다. Q&A 페이지는 한 줄 요약과 상세 설명을 유지합니다. 통계 수치·조사 시점·설명은 제공된 원고대로 표시합니다. 실제 출처의 내용과 일치하는지를 이 검사가 보증하지는 않습니다. 타임라인의 링크 37개는 괄호에 붙은 링크까지 원고 그대로 유지하고 순서·주소를 검사합니다. 2026-10-22 외부 접속을 다시 확인했으며, 고유 주소 19개 중 차별금지법제정연대의 단식농성 보도자료는 HTTP 200입니다. 나머지 정부·국회 사이트 18개는 연결 시간 초과 또는 HTTP 503으로 원문 열림 여부를 확인하지 못했습니다. 이 결과를 근거로 원고의 주소를 임의 변경하지 않았습니다.

뉴스레터는 사용자의 선택에 따라 외부 스티비 구독 페이지로 연결합니다. 리플렛·후원도 제공된 링크를 사용합니다. 리플렛 버튼은 사용자 요청대로 ‘리플렛 신청하기’로 표시합니다.

사이트 링크 공유 버튼은 현재 사이트의 루트 주소를 클립보드에 복사하고 ‘링크가 복사되었습니다’를 표시합니다. 브라우저 공유창을 열지 않으며, Clipboard API를 사용할 수 없으면 복사 대체 동작을 시도합니다.

자료 8개는 사용자가 마지막으로 제공한 PDF·구글 드라이브·유튜브 주소를 그대로 자료 보기 버튼에 연결합니다. 공식 소개 페이지를 거치는 기존 연결은 제거했습니다. 2026-10-22 PDF 4개는 HTTP 206과 PDF 헤더를, 구글 드라이브 2개는 HTTP 200을 확인했습니다. 유튜브 2개는 환경의 접근 제한으로 재생 여부를 검증하지 못했습니다. 링크 주소 자체는 제공된 원문과 대조했습니다.
