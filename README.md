# 차별금지법 안내 사이트

디자인 가이드 v1.3(2026.10.21)을 적용한 정적 사이트입니다. Node.js와 Python 3.12 이상을 사용합니다. Python 생성기에는 외부 패키지가 필요하지 않습니다.

```sh
npm ci
npm run dev
```

개발 서버는 3000번 포트에서 실행하며 확장자가 없는 페이지 주소와 `.html` 리디렉션을 지원합니다. Vercel에서는 `vercel.json`의 `public` 출력 경로와 `cleanUrls` 설정을 사용합니다.

## 수정과 검증

- 제공된 원고: `content/manuscript.json`
- 상세 원고 원본: `content/details.txt`
- 제공된 타임라인 링크 원문: `content/timeline-links.md`
- 공통 HTML과 생성기: `scripts/build.py`
- 디자인 토큰·공통 컴포넌트·반응형 레이아웃: `public/assets/css/style.css`
- 메뉴·문답·공유: `public/assets/js/main.js`

```sh
npm run generate
npm run check
```

원고나 템플릿을 수정한 뒤 HTML을 생성하고, 변경된 `public/*.html`도 함께 반영합니다. 생성된 HTML만 직접 수정하면 다음 생성 시 사라집니다. `check`는 임시 디렉터리에서 다시 생성한 결과와 배포 파일을 비교하고 내부 페이지·앵커·자산 링크, 중복 ID, 접근성 속성의 참조를 검사합니다. 외부 사이트의 내용이나 법률 해석을 검증하는 명령은 아닙니다.

화면 변경 시 320·390·768·1100·1440px에서 글자 줄바꿈과 가로 넘침을 확인합니다. 키보드 메뉴 조작과 Escape 후 초점 복귀, 문답 검색·모두 펼침·직접 링크, 연표의 시기 이동, 움직임 줄이기도 확인합니다. 영역 카드의 노란 표시 높이와 장면 카드의 원형 표시·문장 중앙 정렬도 확인합니다. JavaScript가 꺼져도 페이지 탐색, 문답 펼침과 전체 장면·연표 읽기가 가능합니다.

## 디자인 기준

핑크 `#F375B5`, 퍼플 `#7056BE`, 옐로 `#FCD783`와 화이트·웜 그레이·잉크를 사용합니다. 본문은 18px/1.75, 제목은 Hahmlet 600·700입니다. 콘텐츠 최대 폭은 1,200px, 긴 본문은 720px입니다. 첫 화면의 검정 히어로는 가이드의 화면 예시를 따릅니다. 이전의 화면 전체 패널·굵은 테두리 스타일을 덧씌우지 않고 공통 컴포넌트로 관리합니다.

글꼴은 제공된 가이드에 포함된 Hahmlet와 Noto Sans KR의 WOFF2를 `public/assets/fonts/`에서 직접 제공합니다. 두 글꼴의 SIL Open Font License도 같은 디렉터리에 포함합니다. 외부 글꼴 서비스 연결은 필요하지 않습니다.

## 원고와 외부 연동

사용자가 제공한 원고를 `content/manuscript.json`에 보관하고 HTML은 이 원고에서 생성합니다. 상세 내용은 첨부 원본인 `content/details.txt`와 대조합니다. 원고의 문구를 고치거나 추가하려면 변경안과 이유를 먼저 보고하고 사용자 확인을 받아야 합니다. 디자인 가이드의 설명 문구를 사이트 원고로 사용하지 않습니다.

`npm run check`는 원고의 제목·본문이 상세 원본과 일치하는지, `data-manuscript`로 표시된 출력 문구와 나머지 한국어 본문이 원고에 있는지 검사합니다. 메뉴·검색·공유 상태 같은 기능 표시는 별도로 구분합니다. 미리보기·메타 설명도 원고의 문구를 사용합니다.

문답 9개, 일상 사례 23개, 연표 사건 11개, 자료 소개 8개를 유지합니다. 홈과 Q&A에서 핵심 답변을 먼저 읽고 상세 설명을 펼칠 수 있습니다. 통계 수치·조사 시점·설명은 제공된 원고대로 표시합니다. 실제 출처의 내용과 일치하는지를 이 검사가 보증하지는 않습니다. 타임라인의 링크 37개는 괄호에 붙은 링크까지 원고 그대로 유지하고 순서·주소를 검사합니다. 고유 주소 19개는 이 환경의 외부 접근이 403으로 차단되어 원문 열림 여부를 확인하지 못했습니다.

뉴스레터는 사용자의 선택에 따라 외부 스티비 구독 페이지로 연결합니다. 리플렛·후원도 제공된 링크를 사용합니다. 자료 소개는 자료 보기 버튼으로 연결합니다. 실제 URL이 제공되지 않은 항목의 버튼은 비활성 상태이며, 링크나 임의의 준비 안내문을 만들지 않습니다.
